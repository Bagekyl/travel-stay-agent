# 行程规划规则

## 两天一晚
- 核心原则是减少跨区域移动，住宿点通常应靠近主要活动区域。
- 美食型行程优先骑楼老街、国贸或海甸岛生活区。
- 商务型行程优先会议地点、国贸 CBD、国兴 CBD 或会展中心周边，并用 Routes API 校验实际通勤。
- 度假型行程优先西海岸或观澜湖，到达后减少外出。
- 如果 Routes API 显示单程通勤明显偏高，应降低该酒店优先级，除非用户明确接受。

## 三天两晚
- 可以选择一个主住宿区域，也可以拆分为城市段和度假段。
- 城市漫游与美食可优先龙华区、骑楼老街和国贸。
- 城市加海滩可考虑一晚市区、一晚西海岸，但需评估换酒店成本。
- 亲子纯度假通常优先西海岸或观澜湖，减少换酒店和跨城移动。
- 访校加城市行程通常优先海甸岛，也可结合国贸或国兴作为城市补充。

## 短途中转
- 交通节点距离、接驳可靠性和睡眠恢复比品牌和景观更重要。
- 早班机优先美兰机场周边，并用 Routes API 判断接驳耗时。
- 早班高铁优先海口东站商圈。
- 晚到旅客通常先入住接近到达节点的可订酒店，次日再根据行程切换区域。
- 过夜轮渡或普速列车衔接可考虑海口站/新海港方向基础住宿。

## 亲子行程
- 减少移动频率，酒店本身的设施和安全性应进入核心排序。
- 家庭房、连通房、泳池、儿童活动空间和周边餐饮便利是重要加分项。
- 观澜湖偏目的地型度假，西海岸偏海滩和会展配套，市区偏餐饮与短途便利。
- 不建议频繁换酒店，除非行程明确拆分城市段和度假段。

## 情侣行程
- 景观、氛围、安静度和餐饮品质通常优先于房间数量和亲子设施。
- 滨海大道、西海岸和观澜湖可根据预算与行程重心排序。
- 经济型酒店不是默认排除项，但当用户强调纪念日、蜜月或私密体验时应降权。

## 商务行程
- 效率优先，住宿区域应围绕会议地点、办公区或会展中心确定。
- Wi-Fi、工作区、早餐效率、发票和交通可靠性是关键因素。
- 会展旅客优先西海岸会展中心周边，但展期价格和取消政策需单独检查。
- 不应为了景观或度假设施显著增加通勤。

## 纯度假
- 酒店设施和区域环境可高于城市便利性，但仍需考虑到达、用餐和临时外出的成本。
- 观澜湖适合高尔夫、温泉和目的地型酒店体验。
- 西海岸适合海滩、亲子和免税购物结合。
- 市区商务酒店通常不作为纯度假首选，除非用户预算或交通需求明确。

## 美食型旅行
- 住宿点应靠近餐饮集中区，减少餐前餐后通勤。
- 骑楼老街、国贸和海甸岛生活区分别对应老城小吃、商业餐饮和学生生活区餐饮。
- 西海岸和观澜湖可作为度假选择，但不应为强美食需求用户默认推荐。

## 城市漫游
- 住宿点应尽量位于主要兴趣点之间，减少折返。
- 骑楼老街、海口湾公园、万绿园、世纪大桥和国贸区域可共同影响市区酒店排序。
- 机场和观澜湖通常不适合密集城市漫游，除非用户另有交通或度假目的。

## 访校/考试
- 海南大学相关行程优先海甸岛，重点是安静、距离、价格和出行稳定。
- “访校”语义应由 target_users、trip_styles 和 summary 表达，不需要扩展酒店标签。
- 考试当天应提高路线冗余，避免跨区域通勤。
