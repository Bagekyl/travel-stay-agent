# 天气调整规则

## 高温
- 户外无遮阳景点、登山类景点和长时间步行行程应降权，可调整到上午较早或傍晚。
- 海南省博物馆、日月广场、中免海口国际免税城等室内地点可作为替代。
- 酒店推荐可提高室内公共空间、泳池、餐饮和空调稳定性较好的酒店权重。
- 亲子用户应优先减少户外暴晒和跨区移动。

## 高降雨概率
- 海边、公园、火山群公园、野生动植物园、云洞图书馆室外区域等户外活动应降权。
- 室内购物、博物馆、酒店内设施和靠近商圈的住宿区域可提高优先级。
- 老城区低洼和步行街场景需提醒积水、打车上下车和行李搬运不便。
- 推荐排序应结合天气 API 的实时预报，而不是固定季节判断。

## 强降雨
- 户外景点通常应取消或改期，尤其是登山、海边和远郊亲子景点。
- 当天可优先安排酒店内活动、室内商业和博物馆。
- 酒店推荐可提高设施完整、餐饮便利、靠近大型商场或交通更稳定区域的权重。
- 不应在缺少可靠数据时断言某家酒店拥有特定应急能力。

## 大风
- 海边活动、轮渡和高层海景体验均需谨慎处理。
- 新海港用户必须查询实时通航状态。
- 海边高层酒店可能受风噪影响，应根据用户对景观和安静度的取舍排序。
- 观澜湖等非海边目的地可作为部分度假需求的替代，但高尔夫等户外项目仍受影响。

## 台风风险
- 台风预警后，户外活动、海边、远郊景点、航班、铁路和轮渡都应进入高风险判断。
- 应优先支持免费取消或改期的酒店产品，并提醒用户关注官方预警。
- 可优先考虑运营体系和内部餐饮设施更完整的酒店，但具体备用电源、物资储备和应急保障能力不应在缺少可靠数据时直接断言。
- 系统应把实时天气、交通状态和酒店政策作为最终判断依据。
