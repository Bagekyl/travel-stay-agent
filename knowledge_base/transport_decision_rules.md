# 交通决策规则

## 早班飞机
- 用户存在上午较早航班、夜间到达后次日继续飞行、携带老人儿童或大件行李时，应显著提高美兰机场周边酒店优先级。
- 酒店到航站楼的实际耗时应以 Routes API 返回结果为准，RAG 只提供“早班交通应减少不确定通勤”的判断逻辑。
- 如果 Routes API 显示机场周边酒店到航站楼仍需较长接驳，或酒店无可靠接驳条件，应降低其优先级。
- 机场周边经济型酒店适合短暂停留，不应按常规度假或城市游览标准评价。

## 晚间到达机场
- 晚间到达且用户疲劳、行李多或次日仍有交通衔接时，通常优先机场周边或可确认接驳的酒店。
- 如果第二天无早班需求，次日上午再换到市区酒店是合理方案。
- 不应把机场到市区、西海岸或其他区域的固定分钟数写成永久事实，系统应调用 Routes API 判断当日路线耗时。

## 航空中转
- 中转停留很短时，一般不需要酒店。
- 夜间中转或覆盖睡眠时段时，机场周边酒店优先级显著提高。
- 中转时间较长且用户有城市游览意愿时，可考虑市区酒店，但应把往返机场的真实路线时间、行李寄存和交通可靠性纳入判断。

## 早班高铁
- 从海口东站较早出发时，应优先海口东站商圈或能被 Routes API 证明通勤稳定的酒店。
- 国贸、国兴等市区酒店只有在实际路线耗时可控、用户更重视城市便利或商务地点时才作为备选。
- 西海岸、观澜湖、海甸岛等区域在早班高铁场景下通常降权，除非 Routes API 结果和用户偏好支持。

## 环岛铁路中转
- 中转时间较短时，一般以车站内外短暂停留为主，不必为了住宿扩大移动范围。
- 需要过夜时，东站周边和国兴 CBD 可作为主要候选；前者偏交通效率，后者偏城市配套。
- 行李多、老人儿童同行或天气不稳定时，应进一步提高近站酒店优先级。

## 海口站与新海港
- 海口站和新海港方向主要服务普速列车、轮渡和自驾进出岛衔接。
- 如需过夜等待，应优先选择距离交通节点近、停车或接驳条件清楚的基础型酒店。
- 非交通衔接场景下，不建议把海口站/新海港方向作为常规旅游住宿基地。
- 轮渡受天气和节假日影响明显，系统应提醒用户查询实时通航信息。

## 自驾进出岛
- 自驾用户应优先过滤停车条件，老城区和骑楼老街步行区酒店通常需要降权。
- 西海岸、观澜湖和部分大型酒店更容易满足停车与装卸行李需求，但具体停车收费和车位数量仍应以酒店实时信息为准。
- 节假日或恶劣天气下，应为轮渡和跨区移动预留更高时间冗余。

## 路线时间与房价
- 系统应优先使用 Routes API 的真实路线时间，而不是直线距离或知识库中的固定分钟数。
- 当交通节点酒店价格明显高于市区酒店时，应同时比较房价差、打车成本、路线耗时、出发时段和用户疲劳风险。
- 对早班机、早班高铁、轮渡衔接等场景，可设置策略阈值；阈值用于推荐排序，不代表某条路线的永久事实。
