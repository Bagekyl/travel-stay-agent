# 预算策略

## 价格档定义
- ¥180-400：6 家，经济型预算。
- ¥400-800：7 家，舒适型预算。
- ¥800-1500：6 家，高端型预算。
- ¥1500+：5 家，奢华/目的地型预算。
- 以上价格来自 `mock_price_per_night`，仅用于课程演示和 Mock API 过滤，不代表真实实时房价。

## 经济型预算（¥180-400）
- 适合人群：学生、单人旅客、预算敏感旅客、中转旅客、访校家长。
- 预期酒店类型：基础连锁、经济型酒店或站前基础住宿。
- 当前数据集中覆盖老城区、海甸岛、市中心、东站、机场和新海港/免税城方向，适合做预算硬过滤后的基础候选池。
- 优先考虑：安全、干净、交通节点或生活配套、基本 Wi-Fi。
- 不应期待：海景、泳池、行政酒廊、宽敞房间或完整度假设施。

## 舒适型预算（¥400-800）
- 适合人群：多数两人短途旅客、年轻情侣、普通商务旅客、中转但希望睡眠质量更稳定的旅客。
- 预期酒店类型：中端连锁、精品民宿、空港或东站舒适型酒店。
- 当前数据集中覆盖国贸、骑楼老街、海口东站、机场和西海岸等功能场景，适合作为多数短途和普通商务用户的默认预算池。
- 常见取舍：在位置、睡眠质量和基础设施之间取得平衡。
- 西海岸和机场周边在此档位更偏功能性，不应按纯奢华度假期待。

## 高端型预算（¥800-1500）
- 适合人群：商务旅客、品牌酒店偏好者、注重景观和设施的短途旅客。
- 预期酒店类型：国际品牌高端酒店、高端服务公寓或城市高端酒店。
- 当前数据集中覆盖滨海大道、国贸、美兰和西海岸等区域，适合商务、景观、亲子和设施完整度更高的需求。
- 主要优势：品牌稳定性、房间舒适度、商务或休闲设施、餐饮和服务完整度。
- 常见取舍：这个预算可获得明显更好的酒店体验，但未必适合纯目的地型度假。

## 奢华/目的地型预算（¥1500+）
- 适合人群：高预算度假旅客、蜜月情侣、多代家庭、高尔夫或会展高预算旅客。
- 预期酒店类型：城市奢华酒店、西海岸度假酒店、观澜湖目的地型酒店。
- 当前数据集中覆盖国贸滨海、西海岸和观澜湖等高预算场景，应结合用户是否真正使用度假设施、会展位置或高尔夫/温泉目的地属性判断。
- 优先考虑：空间、景观、度假设施、餐饮、服务体验和目的地属性。
- 不应默认追求性价比；应结合用户是否真的会使用酒店设施判断。

## 预算与其他因素
- 预算硬过滤后，应再结合用户类型、trip_styles、交通节点、天气、取消政策和房态排序。
- `availability` 和 `cancellation` 是 Mock 字段，可用于演示过滤，但不能被解释为真实实时房态或真实取消政策。
- 高预算不自动代表最适合；早班交通、访校考试、美食短途等场景中，位置和路线可靠性可能高于星级。
